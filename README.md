# Superpowers CSS Scope

Interactive exercises for learning modern CSS scoping concepts.

## Local development

Install dependencies:

- `npm install`

Start the development server:

- `npm run dev`

Run the test suite:

- `npm run test`

Create a production build:

- `npm run build`

## GitHub Pages deployment

This repository is prepared for automatic deployment to a GitHub Pages project site.

One-time setup in the repository settings:

1. Open **Settings** → **Pages**.
2. Under **Build and deployment**, choose **GitHub Actions** as the source.
3. Save the setting if GitHub prompts for confirmation.

After that, every push to the default branch triggers the `Deploy to GitHub Pages` workflow, which builds the app and publishes the generated `dist/` directory.
