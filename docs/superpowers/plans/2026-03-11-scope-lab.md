# Scope Lab Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an interactive web app that teaches CSS `@scope` through 10 progressive exercises with live code editing, visual goal comparison, and automated validation.

**Architecture:** Vite + Vanilla JS + CodeMirror 6 (lite). Exercises as JS modules. Sandboxed iframe previews. localStorage persistence. Stacked tutorial layout.

**Tech Stack:** Vite, Vanilla JS, CodeMirror 6 (`@codemirror/view`, `@codemirror/state`, `@codemirror/lang-html`, `@codemirror/lang-css`, `@codemirror/theme-one-dark`), Vanilla CSS, Google Fonts (Inter, JetBrains Mono)

**Spec:** `docs/superpowers/specs/2026-03-11-scope-lab-design.md`

### Task 8: First Exercise Module

**Files:**
- Create: `src/exercises/01-basic-scope.js`

- [ ] **Step 1: Create 01-basic-scope.js**

```js
export default {
  id: 'basic-scope',
  title: 'Your First Scope',
  tier: 1,
  concept: '🔬 Basic Scope',
  instructions: `The page below has two sections: a <code>.card</code> and a <code>.sidebar</code>, both containing paragraphs. Complete the <code>@scope</code> rule so that only paragraphs inside <code>.card</code> turn blue — the sidebar paragraphs should remain unstyled.`,
  html: `<div class="card">
  <h2>Card Title</h2>
  <p>This paragraph should be blue.</p>
  <p>This one too!</p>
</div>
<div class="sidebar">
  <h2>Sidebar</h2>
  <p>This paragraph should NOT be blue.</p>
</div>`,
  htmlEditable: false,
  starterCss: `@scope (____) {
  p {
    color: blue;
  }
}`,
  goalCss: `@scope (.card) {
  p {
    color: blue;
  }
}`,
  checks: [
    { type: 'cssContains', pattern: '@scope\\s*\\(\\s*\\.card\\s*\\)', message: 'Use @scope with .card as the scope root' },
    { type: 'hasComputedStyle', selector: '.card p', property: 'color', expected: 'rgb(0, 0, 255)', message: 'Paragraphs inside .card should be blue' },
    { type: 'hasNoComputedStyle', selector: '.sidebar p', property: 'color', notExpected: 'rgb(0, 0, 255)', message: 'Paragraphs inside .sidebar should NOT be blue' },
  ],
  hints: [
    'The @scope rule needs a selector in parentheses to define where styles apply.',
    'What CSS class does the card element have?',
    'Replace ____ with .card',
  ],
};
```
